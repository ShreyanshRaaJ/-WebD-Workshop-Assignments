# Web Designing Workshop-1 Assignments

This repository contains 18 beginner-friendly HTML5 assignments based on the supplied *Web Designing Workshop-1 Assignment Questions* document.

## How to run
1. Open this folder in VS Code.
2. Open any `.html` file.
3. Run it with Live Server, or open the file directly in Chrome, Edge, or Firefox.

## Notes
- Assignment 10 uses `sample-video.mp4` and `sample-audio.mp3` as example local media filenames. Add your own media files with those names to test the controls.
- Assignment 17 demonstrates browser-side HTML validation. The `submit.php` endpoint is shown as required in the assignment reference; it will need a server-side PHP file to process submissions.
- Assignment 8 and Assignment 10 use sample/placeholder media URLs. Replace them with your own assets if required by your instructor.
